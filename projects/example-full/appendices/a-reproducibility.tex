\chapter{Reproducibility Checklist}
\label{app:reproducibility}

Use appendices for material that supports the main argument without interrupting
the narrative.

\begin{enumerate}
    \item Record the data sources and collection dates.
    \item Document the software environment and dependencies.
    \item Preserve the experiment configuration and random seeds.
    \item Explain how to reproduce the reported figures and tables.
\end{enumerate}
